# Cómo usar ColorScheme en Ignite

Ignite permite adaptar el aspecto de tu web al modo claro u oscuro del sistema, usando la propiedad `colorScheme`.

## Ejemplo básico

Define tu tema así:

```swift
struct MyTheme: Theme {
    var colorScheme: ColorScheme = .auto
}
```
